# منابع و نمونه‌های ناشناس‌شدهٔ پیامک بانکی

این سند برای به‌روزرسانی parser محلی (`HeuristicBankSmsParser`) نگه داشته می‌شود.
قالب پیامک‌ها بر اساس بانک، نوع حساب و نسخهٔ سامانه تغییر می‌کند؛ هیچ قالبی «رسمی و ابدی» فرض نشده است.

بررسی انجام‌شده: اکتبر ۲۰۲۶.

## نمونه‌های ناشناس‌شده برای تست (ساختگی)

شناسه‌ها و مبالغ ساختگی‌اند؛ از دادهٔ واقعی حساب/کارت استفاده نشده است.

### ۱) الگوی شبیه تجارت — واریز (تست)

```
حساب: ****1234 / واریز: 1,500,000 ریال / از طریق: پایا / مانده: 12,000,000 ریال / 1403/07/01 14:30
```

- بانک منتسب: تجارت (غیرقطعی)
- نوع: واریز → درآمد
- منبع الگو: خواست محصول + فیلدهای عمومی rade.ir

### ۲) الگوی شبیه ملت — برداشت (تست)

```
برداشت از حساب ****5678 / مبلغ: 250000 ریال / موجودی: 980000 ریال / شماره سند: 998877 / 1403/07/02 09:15
```

- بانک منتسب: ملت (غیرقطعی)
- نوع: برداشت → هزینه

### ۳) نمونهٔ محاوره‌ای (غیررسمی)

```
۱۰۰ تومن از حساب شما پرید
```

- بانک: بلوبانک — **غیررسمی / بدون منبع معتبر قالب**
- نوع محتمل: هزینه؛ واحد تومان

### ۴) رمز یک‌بارمصرف (باید رد شود)

```
رمز پویا: 123456 مبلغ 500000 ریال تا 02:00 معتبر است
```

### ۵) تبلیغاتی (باید رد شود)

```
جایزه ویژه قرعه‌کشی بانک؛ برای شرکت کد تخفیف ABC را بفرستید
```

## پیشنهاد حساب از متن پیامک

حساب پیشنهادی از روی **متن پیامک** و `name` حساب‌های کاربر انتخاب می‌شود (`SmsAccountMatcher`).

- نرمال‌سازی سادهٔ فارسی (`ي/ی`، `ك/ک`، فاصله / نیم‌فاصله)
- اگر چند نام حساب در متن باشد، اولین مورد در ترتیب فهرست حساب‌ها انتخاب می‌شود
- aliasهای متنی بانک (مثل «بانک ملی ایران» / «ملی») فقط برای گسترش تطبیق نام حساب با متن هستند
- پیشنهاد همیشه در فرم تأیید قابل تغییر است؛ تا تأیید کاربر ذخیره نمی‌شود

## محدودیت‌های parser نسخهٔ اول

- استخراج محلی و heuristic است؛ به API یا مدل آنلاین وصل نیست.
- مبالغ در storage به‌صورت ریال هستند؛ تومان فقط در صورت ذکر صریح در متن یک‌بار به ریال تبدیل می‌شود.
- دسته‌بندی از SMS حدس زده نمی‌شود.
- حساب فقط از تطبیق نام روی متن پیشنهاد می‌شود و تا تأیید کاربر ذخیره نمی‌شود.
- متن خام SMS ذخیره یا لاگ نمی‌شود و به شبکه ارسال نمی‌شود.
- تاریخ شمسی/میلادی با `JalaliDateConverter` به `LocalDate` تبدیل می‌شود؛ نمایش UI همیشه شمسی است.
